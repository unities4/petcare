# Продукт

## Задача

Дома живёт собака. У неё бывает рвота, и нужно понять связь с питанием. Кормят
её разные члены семьи, и никто не помнит, кормил ли кто-то другой час назад.

Приложение решает три вещи:

1. Быстро отметить факт («покормил», «была рвота») — за пару секунд, одной рукой.
2. Показать всем участникам одну общую ленту событий, чтобы не кормить дважды.
3. Напомнить пушем, когда пора кормить / дать таблетку / сделать прививку.

## Роли

- **owner** — создал питомца. Приглашает и удаляет участников, редактирует профиль
  питомца, удаляет питомца. Владельцев может быть несколько.
- **caretaker** — добавляет и редактирует свои записи. Не управляет участниками.
- **viewer** — только чтение (например, ситтер или второй ветеринар).

## Главный экран

Лента событий за сегодня, сверху крупная кнопка **«Покормил»** и рядом кнопка
добавления другого события. Под кнопкой — строчка «последнее кормление: 2 ч назад,
Аня». Это главный ответ на главный вопрос, он должен быть виден без прокрутки.

Одно нажатие = событие записано. Уточнения (сколько граммов, какой корм) можно
дописать потом, тапнув запись в ленте. Не заставляйте человека заполнять форму,
стоя над миской.

## MVP (версия 0.1)

- [ ] Вход по 6-значному коду на email
- [ ] Создание питомца, профиль (имя, вид, порода, дата рождения, таймзона, фото)
- [ ] Приглашение участника: ссылка, QR, email
- [ ] Приём приглашения, в том числе незарегистрированным пользователем
- [ ] Кнопка «Покормил» + лента событий
- [ ] Событие «симптом» (рвота, понос, отказ от еды, вялость) с заметкой и фото
- [ ] Установка на домашний экран (манифест, иконки, онбординг-подсказка для iOS)
- [ ] Подписка на push, напоминания о кормлении по расписанию
- [ ] Экран «связь симптомов с питанием»: что ел за 24 часа до эпизода

## Осознанно НЕ в MVP

- Офлайн-очередь записей. Только оптимистичный UI и внятная ошибка при отсутствии
  сети. Полная синхронизация — когда станет ясно, что она реально нужна
- Несколько питомцев у одного пользователя (схема это поддерживает, UI — потом)
- Подписки и оплата (схема заложена, включаем позже)
- Телефон и Telegram как способы входа (схема заложена)
- Экспорт в PDF для ветеринара
- Веб-версия для десктопа сверх того, что и так работает

## Дальнейшие версии

**0.2 — здоровье**
Прививки и обработки от паразитов с датой следующей, напоминания о них,
вес с графиком, визиты к врачу с заметками и файлами заключений.

**0.3 — монетизация**
Тарифы free / pro, оплата картой, лимиты (см. `docs/decisions.md`, ADR-006).

**0.4 — способы входа**
OTP по номеру телефона, вход через Telegram.

**Идеи без срока**
Экспорт истории в PDF, напоминания о конце корма, распознавание текста с
ветеринарных заключений, шаблоны графиков прививок по видам животных.

## Как разбивать работу

Каждая задача — вертикальный срез: миграция + запрос + экран + проверка на
телефоне. Не «сделать всю схему», не «сделать весь UI». Порядок задач в MVP выше
не случаен: приглашения идут вторыми, потому что это самая рискованная часть
модели данных, и ошибку в ней дешевле найти сейчас, чем после десяти экранов.
